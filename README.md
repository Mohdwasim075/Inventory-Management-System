# 📦 Inventory Management System

A modern web-based **Inventory Management System (IMS)** built with **PHP, MySQL (MariaDB), Bootstrap 5, and AdminLTE 4**. The application helps businesses efficiently manage products, suppliers, customers, inventory, purchases, and sales while providing real-time business insights through an interactive dashboard.

---

## ✨ Features

### 📊 Dashboard
The dashboard provides an overview of your business with real-time statistics, including:

- 💰 Today's Sales
- 📈 Today's Profit
- 🛒 Orders Today
- 📦 Items Sold Today
- ⭐ Top Selling Products
- ⚠️ Low Stock Products
- 🧾 Recent Invoices

---

## 📥 Purchase Management

Increase inventory by creating purchase orders.

Features include:

- Create Purchase Orders
- Select Supplier
- Add multiple products
- Update purchase quantities
- Purchase status management
- Automatic stock update after purchase completion
- Purchase history

---

## 🛒 Sales & Invoice Management

Sell products to customers through invoices.

Features include:

- Create Sales Invoices
- Select Customer
- Add multiple products
- Automatic stock deduction
- Calculate totals
- Profit calculation
- Invoice history
